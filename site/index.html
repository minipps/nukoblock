your time, intentionally._

daily time budgets for sites, for Chrome and Firefox.

install github

what it does

  • give each site a daily budget. new entries start at 30 min/day.
  • pick a mode per site: track (just count), limit (blocked once the budget runs out, resets at midnight) or block (always).
  • weekly schedules override the base budget. overnight windows count toward the day they start.
  • an optional pause before entering: breathe, pick something else to do, say how you feel, or decide how long to stay.
  • 30 days of stats, drawn in ASCII.
  • themes: mocha, latte, phosphor, amber, sakura, or your own colors.

private by design

  • everything stays in your browser. no telemetry, accounts or servers.
  • time counts for the focused tab and audible background tabs. several tabs of one site count once.
  • it's a self-control tool, not tamper protection. embedded content and private windows aren't covered.

install

firefox

get it on addons.mozilla.org

chrome

  1. download the -chrome.zip from the latest release and unzip it.
  2. open chrome://extensions and turn on developer mode.
  3. click load unpacked and pick the unzipped folder.

from source

git clone https://github.com/minipps/nukoblock
cd nukoblock && npm ci && npm run build
